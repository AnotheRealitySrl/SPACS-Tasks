# Virtuademy-SDK-Tasks

## How to install

Import from Git URL using Unity Package Manager: `https://github.com/AnotheRealitySrl/Virtuademy-SDK-Tasks.git`

Alternatively, if you need to modify the content of the package, import it as a submodule under the `Packages` folder.

Dependencies:

- `com.anotherealitysrl.virtuademy-sdk-graphs` (brings `com.anotherealitysrl.spacs-utility`)
